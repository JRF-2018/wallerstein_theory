# Extension レポート: kant.matcha

対象: `tests/skill_runs/kant/kant.matcha`（花房孟胤「三段論法をハックする」の画像を書き起こしたもの。法律以外の論証で、カント『判断力批判』の「美しい芸術」の定義を SHEET_BOXING プロジェクトにあてはめる）

生成物: `kant.mext`（審査後の理論）、`kant.asis.mext`（書かれたとおりの理論）、`kant.lean`、本レポート。

注意: L2 の `~>` の内容（「美しい芸術」の定義文）は構文木では `[事実]` として読まれているが、`mext.py` の変換では**原子命題にならず、理論から落ちている**（`[atoms]` に現れない）。そのため定義の「必要条件」としての性格を `[extra]` で補った（2 章）。

## 2. AI の判断（[ai] と [extra]）

### [ai]

| 種類 | 対象 | 判断 | 理由 |
|---|---|---|---|
| neg | 「#SHEET_BOXINGプロジェクトはアートといえるか^カントの判断力批判 [L1]」と「SHEET_BOXINGプロジェクトはアートではない」 | 結論は主張の否定 | 主張は「アートといえるか」という問いで、結論はその否定の答え |
| same | — | なし | 同じ命題の別表記は見当たらない |
| failure / effect | L15 の結論 | 書かない | 既定の読み（主張 L1 の不成立からの帰結）が正しい |
| review | — | 該当なし | 評価（`@`）の原子がない。あてはめの飛躍は 6 章で論じる |

### [extra]（足した背景知識）

| 規則 | 理由 |
|---|---|
| ¬r4 → ¬r3 | L8 は L7「目的なき合目的性」の定義（言い換え）なので、定義が成り立たなければ被定義項も成り立たない。mext.py は r4 → r3 しか作らない |
| ¬r6 → ¬r5 | L12 は L11「美的理念」の定義なので同じ |
| ¬r3 → ¬k1 | L2 の `~>` は「美しい芸術」を 3 要件の連言で定義する。各要件は必要条件である（mext.py では `~>` の内容が落ちているので補う） |
| ¬r5 → ¬k1 | 同じ（第 3 要件） |

これらは原文が明示している「定義」の構造を規則にしただけで、カント解釈を新たに足したものではない。ただし、L2 の定義を「必要十分条件」と読むこと自体は解釈である（6 章）。

### 保留した判断

- 「SHEET_BOXINGプロジェクト」（主張の対象）と「拳譜」（L9 の主語）、および L13 の主語なし事実の主体の同一視。理論には主体の原子がないので宣言の必要はないが、論証上は問題になる（6 章）。
- f2「拳譜は…目的を持っている」を r4（それ自体に目的を持たない…）の否定とみなすこと。これはすでに Matcha の `!` の伝播で規則 `f2 → ¬r4` になっているので、`neg` は書かなかった。

## 4. Extension

（mext.py の出力）

```
E1:
  generating: L1.不成立
  literals: -k1, r1, r2, f1, -r3, -r4, f2, -r5, -r6, f3
```

Extension は **1 個**（E1）。優先順位がないので E1 が preferred。

## 6. あてはめの実質的妥当性

評価（`@`）がないので review の対象はなく、`kant.asis.mext`（審査を反映しない理論）と `kant.mext` の生成部分は同一である（diff で確認）。しかしこの論証では、あてはめが `@` 評価ではなく `<=`（確定規則）で書かれているため、争いうる飛躍が確定規則に埋まっている。AI として次のように審査する（理論には反映していない）。

| あてはめ | 審査 | 理由 |
|---|---|---|
| f1「新しい記号体系を与えた」→ r2「芸術に規則を与える生得的な心的資質」 | doubtful | 新しい記法を作ったことは「規則を与えた」とはいえても、それが「芸術に」与えたものか、また「生得的な心的資質（天才）」によるかは別問題。前者は結論（芸術か）を先取りしており循環のおそれがある。カント（§46–47）では天才の規則は模倣できない範例性を持つもので、学習可能な記法体系はむしろ「学」や機械的技術の側にある、という反論もありうる |
| f2「拳譜は…記録し議論する目的を持つ」→ ¬r4「目的なき合目的性がない」 | doubtful | カントの「目的なき合目的性」は判断における対象の表象の形式についての話で、対象が実用目的を持つことと両立しうる（§16 の付随美 pulchritudo adhaerens）。また主語が「SHEET_BOXINGプロジェクト」から「拳譜」へずれている |
| f3「ノーテーションの1類型と説明できる」→ ¬r6「特定の概念に規定されない、ではない」 | doubtful（reject に近い） | ある類型に分類できることは、その表象が「一つの概念によって完全には汲み尽くされない」ことを否定しない（どの芸術作品も「絵画の一類型」と説明できる）。分類可能性と概念による規定とを取り違えている |
| L2 の定義を必要十分条件と読むこと／「美しい芸術」でない → 「アートではない」 | doubtful | カントは「機械的技術」「快適な技術」も技術（Kunst）と呼ぶ（§43–44）。「美しい芸術でない」から「アートでない」への移行には、アート＝美しい芸術という前提が要る。結論は「美しい芸術（schöne Kunst）とはいえない」に留めるのが正確 |

これらは `<=` で書かれているため `review` で外せない。争うには原典を `@` 評価の形（例: `拳譜は…目的を持っている@目的なき合目的性がない`）に書き直す必要がある。

## 7. 懐疑的帰結と信憑的帰結

（mext.py の出力）

- 懐疑的（すべての Extension で成り立つ）: ¬#SHEET_BOXINGプロジェクトはアートといえるか^カントの判断力批判 [L1]
- 信憑的（いずれかの Extension で成り立つ）: ¬#SHEET_BOXINGプロジェクトはアートといえるか^カントの判断力批判 [L1]

Extension が 1 つなので両者は一致する。すなわち「SHEET_BOXINGプロジェクトはアートではない」（neg により ¬k1）は懐疑的帰結である。

## 8. 反論の候補（立証責任）

- 結論 ¬k1 は、第 2 要件の側（f2 → ¬r4 → ¬r3）と第 3 要件の側（f3 → ¬r6 → ¬r5）の**二重の根拠**で導かれる。結論を覆すには両方を崩す必要がある。
- 両方を崩しても（f2・f3 が r4・r6 の否定の根拠にならないとしても）、変換後の理論では `L1.不成立: ⊤ : -k1 / -k1` により結論は残る。肯定側が k1 を得るには、r3 と r5 を**積極的に**基礎づける事実（作品の受容が多くの思考を喚起すること、実用目的と独立に形式が合目的的に感じられること等）を立証し、x1 を成立させなければならない。つまり立証責任は「アートである」と主張する側にある、という構造になっている。
- 注意: `neg` の宣言により、仮に x1 が成立しても、¬k1 を含む集合が `L1.不成立`（前提 ⊤、正当化 ¬k1）自身によって支えられ、{k1} と {¬k1} の 2 つの Extension に分かれうる（[extra] の必要条件規則がない場合。スクラッチで r3・r5 を事実として足して solve し、Extension 2 個になることを確かめた。neg を宣言しなければ 1 個）。本件では x1 が導けないので問題にならないが、主張デフォルトと不成立デフォルトの間に優先順位がないことは変換の性質として留意すべきである。

## 10. 結論

**(a) 形式的妥当性**: 主張された結論「SHEET_BOXINGプロジェクトはアートではない」は、唯一の（したがって preferred の）Extension E1 に含まれ、懐疑的帰結である。著者の成否の印もすべて一致する。ただし、書かれたとおりの変換では結論は事実に依存せず「主張が立証されていない」ことだけから出ており、著者の挙げた不成立の根拠を結論につなぐには、定義の必要条件性（[extra] の 4 規則）を補う必要があった。

**(b) 実質的妥当性**: 説得力は弱い。三つのあてはめはいずれも確定規則（`<=`）として書かれているが実際には争いうる評価であり、とりわけ第 3 要件（「ノーテーションの一類型である」から「美的理念を持たない」）は分類可能性と概念による規定を混同している。第 2 要件も、実用目的の存在と「目的なき合目的性」は付随美の議論のもとで両立しうるうえ、主語が「プロジェクト」から「拳譜」へずれている。さらに「美しい芸術でない」から「アートでない」への移行には追加の前提が要る。結論として妥当に言えるのは「この論証の示す限りでは、SHEET_BOXINGプロジェクトがカントの意味での美しい芸術であることは立証されていない」までである。

原典の表記について（ファイルは直していない）: L2「目的なき合目的性が備え」は「目的なき合目的性を備え」または「が備わり」の誤記と思われる。
