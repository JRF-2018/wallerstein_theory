## 6. あてはめの実質的妥当性

### review の表

§2 の表のとおり、3 件とも **doubtful** で、reject はない。したがって、書かれたとおりの理論（asis）は本体と同一である。

### 構造の問題・事実の食い違い・誤記の疑い（AI の判断）

1. **対象のずれ（第2要件）**: 主張の対象は「SHEET_BOXING プロジェクト」だが、第2要件の根拠事実の主語は「拳譜」である。プロジェクトが拳譜という記譜法を素材や媒体として使っていても、プロジェクト（作品・活動）の目的は記譜法の実用目的と同じとは限らない。記譜法を美的な対象として提示すること自体が、プロジェクトの狙いでありうる。この同一視は、原文のなかで根拠づけられていない。
2. **第1要件の「資質」と「成果」**: 定義は天才を「生得的な心的資質」とするが、根拠事実は成果（記号体系を与えた）である。成果から資質を推認することはありうるので、飛躍は小さい。ただし、記号体系は**概念的な規則**である。そのため「天才が芸術に規則を与える」（規則を概念として定式化できない、§46）の典型からは外れる。第1要件を成立（+）とする著者の判断と、第2・第3要件を不成立とする判断（目的があり、概念で説明できる）は、同じ「記号体系という概念的な性格」をめぐって逆方向に働いている。**整合性が問われる**。
3. **理由 y1 の位置づけ**: `~>` の理由「天才によって規則を生み出し、目的なき合目的性が備え、美的理念を有する表象である」は、カントの所説を著者が三要件の必要十分条件として再構成したものである。カント自身はこれをこの形の定義として述べてはいない（とくに目的なき合目的性は、主に趣味判断・自由美の分析の文脈で語られる）。変換では `⊤ : y1 / y1` で前提として受け入れているが、実質的には著者の解釈である。
4. **結論の射程（最も重要）**: 論点は「美しい芸術とは」、根拠はカントの**美しい芸術**の定義である。しかし `>>` の結論は「アートではない」となっている。三要件の不成立から導けるのは「カントの意味での美しい芸術にはあたらない」までであり、芸術一般の否定ではない。カントの体系でも、機械的芸術・快適な芸術は（美しくない）芸術として残る（§43–44）。
5. **不成立からの帰結の強さ**: §4 で見たとおり、c1 は「k1 が立証されないこと」だけで出る。つまりこの論証の形は、「アートである」側に立証責任を負わせている。根拠事実 f2・f3 を取り除いても結論は変わらない（下の試算 A）。

誤記の疑い: 原典の明らかな誤記は見当たらない（L4 の字下げ警告は形式だけの問題）。

## 8. 反論の候補（立証責任）

（AI の判断）

| 争点 | 反論側がすること | 効果 |
|---|---|---|
| 第2要件（目的なき合目的性） | 対象のずれを指摘する（拳譜の目的≠プロジェクトの目的）。そのうえで、展示物が用途を離れて合目的的に感じられることを立証する | ¬r3 の根拠が消え、r3 が成立しうる |
| 第3要件（美的理念） | 分類≠完全な規定を指摘する。そのうえで、図像が一つの概念に収まらない多様な思考を引き起こすことを立証する | ¬r5 の根拠が消え、r5 が成立しうる |
| 結論の射程 | 「美しい芸術でない」から「アートではない」は出ないと主張する | 結論 c1 そのものの射程を限定する（形式の外の反論） |

不成立の根拠は二つが独立しているので、**両方**を崩さなければ ¬k1 は消えない。さらに c1 は k1 の不立証だけで出るので、結論を覆すには、**第2・第3要件を積極的に立証して k1 を成立させる**必要がある。

なお、この理論では「不成立の根拠」（f2 → ¬r4、f3 → ¬r6）は評価デフォルトではなく**確定規則**である（`@評価` のない `<=` だから）。そのため、根拠を残したまま反対の事実を `[extra]` の規則で足すと r4 と ¬r4 が両方導かれ、Extension がなくなると予想される（変換規則からの推論で、**試していない**）。試算 B で reject と組み合わせたのは、このためである。原典の著者が `@` を付けて評価として書いていれば、反対の事実を足しても Extension は消えず、別の Extension に移るだけで済んだ（docs/mext.md §2 末尾）。

## 9. 予測した Extension の検証

予測（`[claimed]`）:

```
E1*: -"#SHEET_BOXINGプロジェクトはアートといえるか^カントの判断力批判", "SHEET_BOXINGプロジェクトはアートではない", "%天才によって規則を生み出したこと", -"%目的なき合目的性が備えていること", -"%美的理念を有する", -"? 美しい芸術とは"
```

予測の理由: 第2・第3要件に不成立の根拠事実があり、AND が否定されるので主張は不成立となる。不成立からの帰結として「アートではない」が出る。第1要件は成立する。

（mext.py verify の出力）

```
E1: OK（主張されたリテラルを満たすpreferred Extension: E1）
```

予測は当たった。書き直しはしていない。ただし手順上、`init` の時点で求解結果がすでに生成部分に出力されていた（手順 2）。そのため、この予測は求解結果を見る前の完全に独立した予測ではない。正直に記しておく。

## 10. 結論

**(a) 形式的妥当性**: 主張された結論「SHEET_BOXINGプロジェクトはアートではない」は、唯一の（preferred）Extension E1 に含まれる。懐疑的帰結でもある。著者の成否の印 4 か所もすべて Extension と一致する。Lean 証明（`kant.lean`、E1 が Γ(E1)=E1 を満たすこと）は `lean kant.lean` でエラーなく通った。形式的には、**論証は書かれたとおりに成り立つ**。

**(b) 実質的妥当性**: 説得力は**限定的**である。
- 二つの不成立の根拠（第2・第3要件）はいずれも doubtful である。第2要件には「拳譜」と「プロジェクト」の対象のずれがある。第3要件は、分類できることから概念による完全な規定へと飛んでいる。
- 第1要件を成立とする判断と、第2・第3要件を不成立とする判断のあいだで、「記号体系の概念的な性格」の扱いが逆向きになっている。
- 最大の問題は**結論の射程**である。論証が示しうるのは「カントの意味での美しい芸術にはあたらない」までで、「アートではない」ではない。
- 結論は「アートであること」の不立証だけで出る形になっている。根拠事実を争っても結論は動かない（試算 A）。結論を覆すには、反対側が積極的な事実を立証しなければならない（試算 B）。この立証責任の配分が妥当かどうかも、それ自体が論点になる。
