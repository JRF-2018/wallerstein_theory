## Sim 1: 中核／半周辺／周辺の創発（`sim1_core_periphery.py`）

**モデル**（累積的因果。Myrdal・Kaldor の考え方で、Krugman & Venables 1995 と同じ型）:

- N 地域がリング状に並ぶ。地域は移動しない労働と、工業の能力 x_i を持つ。
- 工業の生産性は A_i = (1+x_i)^ψ。
- 地域 j の工業品購入のうち i から買う割合は S_ij = A_i^θ φ^{d_ij} / Σ_k A_k^θ φ^{d_kj}。
- 所得は Y = b + μSY。
- 能力は生産から学習する（Verdoorn 則）: dx_i/dt = βR_i − δx_i。
- パラメータは μ=0.5, θ=5, ψ=0.5, β=δ=1。

**結果**:

1. **対称性の破れの閾値（解析）**: 2 地域の対称な均衡は、K·h(φ) > 1 のとき不安定になる。
   - h(φ) = φ / ((1+φ)(1−μ+(1+μ)φ))、K = 5。
   - 閾値は **φ\* ≈ 0.184**。数値計算の分岐図もこれと一致した。
   - h は φ = √((1−μ)/(1+μ)) ≈ 0.577 で最大になる（逆 U 字形）。
   - 履歴効果は φ ≈ 0.18〜0.20 のわずかな幅にしかない。
2. **10 地域**: φ=0.3 では中核が 2 つでき、その間にある地域が半周辺になる（IROWS の interstitial の論点）。φ ≥ 0.6 では中核が 1 つだけになる。
3. **グローバル化の経路**（20 地域、φ を 0.1 → 0.9 へ上げる）:
   - 中核は **10 → 5 → 3 → 2 → 1** と統合されていく（ヘゲモニーへの集中）。
   - **半周辺は統合の移行期にだけ現れる**（没落しつつある中核と上昇しつつある周辺）。
4. **不等価交換**: 輸出に体化された労働と輸入に体化された労働の比は、周辺で 1.5〜3.2、中核で 0.3〜0.7。周辺は、受け取る労働の数倍の労働を渡している。
5. **正直に記録しておく結果**: 周辺の一次産業所得を 20% 下げると、中核の所得も 16〜17% 下がる（需要を通じた波及）。
   - したがって「周辺の不平等が中核に及ばない」という命題は、周辺の所得の**総額**については成り立たない。
   - そこで、周辺の**内部での分配**（非正規化）について Sim 2 で検証する。

## Sim 2: 周辺における非正規雇用（`sim2_labor_market.py`）

**モデル**:

- **労働市場**: Harris & Todaro 1970 型の二重労働市場。職の総数は λL で、λ < 1 なら労働余剰（Lewis 1954）がある。
- **企業**: 異質な企業が、安定した職ごとに正規か非正規かを選ぶ。
  - 正規の価値: 技能による生産性の上乗せ − ナッシュ交渉で決まる賃金 − 外資の撤退ハザード h_F による解雇費用の負担。
  - 非正規の価値: 生産 − 賃金 − 入れ替えの費用。
- **非正規の賃金**: 非正規の層には固有の不就業率 e₀ がある。それ以外の労働者は正規職の列に並ぶ。
  - 正規職に就ける確率: q = min(1, J_R / (L − J_N/(1−e₀)))。
  - 非正規の賃金: w_N = b + q(w̄_R − b)/(1−e₀)。
- 中核は λ=0.97、外資 10%。周辺は λ=0.70、外資 60%。生産性の比は Sim 1 から取った（3.23）。

**結果**:

1. **反転の条件（解析）**:
   - w_N < w̄_R ⟺ q < 1 − e₀ である。
   - さらに q の式を代入すると、**q < 1 − e₀ ⟺ λ < 1 − e₀** となり、非正規の割合が式から消える。
   - つまり、**賃金の序列が反転する（補償賃金 → 身分賃金）かどうかは、労働余剰だけで決まる**（相図の境界は λ = 0.8 の水平線）。
2. **資本の移動性が決めるのは、非正規の「量」と、反転の「深さ」**: 外資の撤退ハザードを 0 → 0.4 に上げたときの変化は次のとおり。

   | 地域 | 非正規の職の割合 | 非正規の賃金 / 正規の平均賃金 |
   |---|---|---|
   | 周辺 | 0.31 → 0.73 | 0.90 → 0.80 |
   | 中核 | 0.31 → 0.34 | 1.11 のまま（補償賃金のまま） |

3. **中核への移転**: 外資が「身分賃金」によって得る差額（補償賃金の水準 − 実際の賃金）× 非正規の職の数は、撤退ハザードとともに **0.022 → 0.101** に増える。
   - 中核の賃金はこの間、変わらない。
   - これが「周辺の不平等の効果は中核に及ばない（むしろ中核に移転される）」の、このモデルでの意味である。
4. **内なる周辺化（仮説の例示）**: 中核で国内資本も移動しやすくなり、職の充足率も下がる経路では、t ≈ 0.78 で q が 1 − e₀ を下回り、中核にも身分賃金が現れる。
5. **複数均衡**: 低い賃金から反復を始めると、臨界点を越えたところで「全面的な非正規化」（q = 0）の均衡に落ちることがある。補償賃金と身分賃金が両方とも均衡になる領域は、このモデルにはなかった。慣行の選択（双安定）は Sim 3 で扱う。

## Sim 3: 事実から慣習規範へ（`sim3_convention.py`）

**モデル**:

- 企業と労働者が、非正規の契約の慣行を選ぶ協調ゲーム。A = 補償原則、B = 身分秩序。
- 学習は Young 1993 の適応的プレイ（記憶 20、見本 6、誤り 0.03）。
- 慣行が食い違ったときの外部オプション:
  - 労働者: 正規職の列に並ぶ価値 u_W = q w̄_R + (1−q) b。
  - 企業: 退出オプション o_F。
- 賃金と利潤は Sim 2 の値から作った。

**結果**:

1. **中核では身分秩序は均衡にならない**: q = 1 なので、身分賃金を示されても労働者は正規職を選ぶ。どの退出オプションのもとでも A が成り立つ。
2. **周辺では両方の慣行が均衡**になる。どちらが確率的に安定かは、**企業の退出オプション**で決まる。
   - リスク支配の閾値（解析）は o_F ≈ 0.052（身分秩序での利潤の 16%）。
   - シミュレーションでは o_F/π_B ≈ 0.19 と 0.22 の間で、B の割合が 0 から 0.97 に跳ねる。
   - **市場（労働余剰）が賃金の序列を決め、力（退出オプション）が慣行を決める**、という二層の構造になる。
3. **慣習の成立**: 補償原則から出発しても、約 1,600 期で身分秩序の慣習が成立する（直近 500 期の 90% 以上が B）。
4. **法的介入**（同一労働同一賃金の執行で、B の利潤を P だけ下げる）:
   - **弱い介入**（P ≈ 0.10。リスク支配性だけを A に戻す）: 2 万期の間、B が続く（慣習の慣性）。
   - **強い介入**（P ≈ 0.27。B を企業にとって均衡でなくする）: B はすぐに崩れる。

## Lean で示す補題（P5 の候補）

1. h(φ) の導関数の符号は (1−μ) − (1+μ)φ² と同じ（Sim 1 の逆 U 字形）。
2. w_N < w̄_R ⟺ q < 1 − e₀ と、q < 1 − e₀ ⟺ λ < 1 − e₀（Sim 2）。
3. π_A < π_B のとき、B のリスク支配度は o_F について増加する（Sim 3）。
4. 第 3 部の MEXT の各 Extension の不動点性（`mext.py lean`）。
