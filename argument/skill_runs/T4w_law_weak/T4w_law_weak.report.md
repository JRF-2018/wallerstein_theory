## 2. AI の判断（[ai] / [extra]）

### same / neg / failure / effect: どれも書かなかった

- **same**: 周辺の「非正規の賃金は正規より低くてよい」は、三つの主張がそれぞれ結論に使っている。
  - 補償原則_周辺: `>> !`
  - 身分秩序_周辺: `>>`
  - 均等待遇_周辺: `>> !`

  三つとも対象が「周辺の非正規の労働契約」で同じなので、変換の時点で一つの原子 c4 になっている（`[atoms]` の行番号は 3 箇所）。中核の c1 と周辺の c4 は、対象が違うので別の原子とする。これは著者の意図どおりで、同一視してはならない。要件の文言はすべて主張ごとに一回しか現れない。前提として繰り返された要件はないので、`same` の必要はない。
- **neg**:
  - c3「中核では非正規の賃金が実際に低いとはいえない」は、「非正規の賃金は実際に正規より低い〔中核〕」の否定のように読める。しかし後者は中核の原子として存在しないので、宣言する意味がない。
  - c6「周辺では均等待遇は実効を欠く」は ¬k8 の言い換えで、すでに `均等待遇の実効_周辺.不成立` のデフォルトで ¬k8 と結ばれている。
  - c2「中核では身分秩序による賃金の切り下げは認められない」と c1 は、互いの否定ではない。c2 は特定の根拠（身分秩序）による切り下げを否定しているだけだからである。
- **failure / effect**: 既定の読みはすべて正しい。
  - 「成立の効果」: 補償原則（中核・周辺）、身分秩序_周辺、実態_周辺、均等待遇_周辺
  - 「不成立からの帰結」: 身分秩序_中核、実態_中核、均等待遇の実効_周辺

## 10. 結論

**(a) 形式的妥当性**

著者が主張した結論は、preferred Extension（ただ一つの E2）にすべて含まれる。

| 層 | 結論 | 根拠 |
|---|---|---|
| 当為（効力） | 周辺では「非正規の賃金は正規より低くてよい」は否定される（¬c4） | 9条が身分秩序を阻却する |
| 存在（実効性） | 「非正規の賃金は実際に正規より低い」（c5） | 執行が弱い |
| 存在（実効性） | 「周辺では均等待遇は実効を欠く」（c6） | 執行が弱い |

当為と存在で反対の帰結が同時に成り立つことは、別の原子として無矛盾に表されている。

著者の印との不一致は `+#身分秩序`（wage_periphery:L10）の一件だけである。これは T3 の文脈で付けられた印が T4w に持ち込まれたためで、論証の誤りではない（§5）。

Lean: `lean T4w_law_weak.lean` で確認した（エラーなし）。E1, E2 がともに Γ(E)=E を満たす。

**(b) 実質的妥当性**

存在の層の論証（c5, c6）は堅い。シミュレーションの観測（0.978、0.102 < 0.241）からの素直なあてはめで、すべての Extension で成り立つ。

当為の層の ¬c4 は、**9条のあてはめ（v9）一つに懸かっている**。

- 二つ目の根拠に見える補償原則は、9条が身分秩序を阻却した結果として復活しているだけである。9条を外せば力の優先順位にふたたび負ける（試算 A）。
