# 第 3 部の分析: シミュレーションから Matcha-D へ（2026-10-19）

## 0. 作り方

- `build_argument.py` が `../sims/out/*.json` を読み、`*.matcha` を生成する（手では直さない）。
  - 各事実の直前の `//` コメントに、出典（JSON のどの値か）を書く。
  - 数値から法的概念への橋渡しは `@評価` として書く。たとえば「撤退ハザード 0.25 は閾値 0.09 を上回る@いつでも引き上げられる」。これがスキルで審査される neuro の部分にあたる。
- 閾値との比較で要件の成否（`+` / `!`）を決める。これは生成器（著者）の主張で、`mext.py` の `[marks]` が Extension と照合する。
- Matcha の約束に従い、不成立の主張の `>>` には不成立からの帰結を書く（「中核では周辺例外は認められない」など）。
- Matcha には変数がないので、規範は地域（中核・周辺・事実の分からない地域U）ごとの事件として具体化する。

| ファイル | 内容 |
|---|---|
| `employment_{core,periphery,unknown}.matcha` | 事実上の規範秩序としての雇用形態。雇用安定の原則（中核の雇用慣行。派遣法 25 条・労契法 18 条の趣旨を反映）と、周辺例外（世界システム上の位置、外資の退出オプション、正規が通常でなくなっていること）`!> $雇用安定` |
| `inverted_{core,periphery,unknown}.matcha` | デフォルトを反転した理論: 非正規原則と、中核特権 `!> $非正規原則` |
| `wage_{core,periphery}.matcha` | 当為の層: 補償原則（Smith、Rosen）と身分秩序（民法 92 条の事実たる慣習）の対立。存在の層: 身分秩序の実態（慣行が続いているか） |
| `power_periphery.matcha` | `:: 優先 $身分秩序_周辺 > $補償原則_周辺`（Sim 3: 退出オプションが閾値を超える） |
| `law_periphery_{weak,strong}.matcha` | 当為の層: 均等待遇（パート有期法 9 条、強行規定）`!> $身分秩序_周辺`。存在の層: 均等待遇の実効 `!> $実態_周辺`（要件「実効的な執行」は Sim 3 の罰の大きさで決まる） |
| `cand_{compensation,status}_*.matcha` | アブダクションの対抗候補（補償原則のみ／身分秩序のみ） |

## 1. 理論と結論（`mext.py` の出力。preferred Extension の懐疑的帰結）

雇用形態の理論（T1、T1i）は、**事実上の規範秩序**（何が「通常」とされるか）を記述する。結論は「期間の定めのない雇用が通常である」とする。対象は「外資の安定した職」にする（退出オプションを持つのは外資だから）。

賃金の理論（T2〜T4）は二層に分ける。

- **当為**（法的評価）: 「非正規の賃金は正規より低くてよい」
- **存在**（事実）: 「非正規の賃金は実際に正規より低い」

| 理論 | ファイルの組 | 中核 | 周辺 | 地域U |
|---|---|---|---|---|
| T1 雇用形態 | employment_* | 期間の定めのない雇用が通常 | **¬**通常（周辺例外） | 通常（原則） |
| T1i 反転 | inverted_* | 通常（中核特権） | ¬通常 | **¬**通常（原則） |

| 理論 | ファイルの組 | 中核（当為／存在） | 周辺: 当為 | 周辺: 存在 |
|---|---|---|---|---|
| T2 賃金 | wage_* | 低くてはならない／実際に低いとはいえない | **決まらない**（2 つの preferred Extension） | 実際に低い |
| T3 賃金＋力 | T2 + power | 同上 | **低くてよい**（身分秩序が優先） | 実際に低い |
| T4w 弱い執行 | T3 + law_weak | 同上 | **低くてはならない**（9 条は強行規定） | **実際に低い**（均等待遇は実効を欠く） |
| T4s 強い執行 | T3 + law_strong | 同上 | 低くてはならない | **実際に低くない** |

すべての理論の各 Extension について、Γ(E) = E を Lean（`decide +kernel`）で確かめた。いずれも 3 秒以内に通る。

## 2. 論点

### (a) デフォルトとは「情報がないときに成り立つもの」であり、立証責任の配分である

- T1 と T1i は、事実の分かっている中核と周辺について、まったく同じ結論を出す。違うのは、事実の分からない地域U についてだけである（T1 では正規、T1i では非正規）。
- `explain` で見ると、その理由が分かる。
  - T1: 地域U の周辺例外は「前提 x3 を欠く … あてはめる事実が書かれていない」ために働かない。例外を主張する側（使用者）が、周辺にあることと退出オプションがあることを立証しなければならない。
  - T1i: 逆に、正規雇用を主張する側（労働者）が、中核にあることと退出オプションがないことを立証しなければならない。
- 「中核＝デフォルト、周辺＝例外」（Grok 会話）という書き方は、記述としての正しさの問題ではない。**立証責任をどちらに負わせるか**という規範的な選択である。
- ウォーラーステインのいう「周辺は例外ではなく、システムに構造的に必要な部分」という論点は、形式的には次のように読める。デフォルトと例外の割り当ては事実からは決まらず（T1 と T1i は既知の事実について同値）、中核の視点（中核のイデオロギーとしての自由主義、川北編 p.76）によって選ばれている。

### (b) 規範の対立（Nixon diamond）と、論理の外から来る優先順位

- T2 では、周辺の非正規の賃金について、補償原則と身分秩序がどちらも適用されうる。結論は二つの preferred Extension に分かれ、懐疑的には何も言えない。
- 優先順位はデフォルト論理の内部では決まらない。T3 は、Sim 3 の結果（企業の退出オプションが閾値 0.052 を超えると、身分秩序がリスク支配的になり、適応的プレイで確率的に安定になる）を根拠に、`:: 優先` を外から与えている。
- 中核では、そもそも対立が生じない。身分秩序の要件「労働者が身分賃金を受け入れる」が、事実（身分賃金 2.209 < 正規職の列に並ぶ価値 2.548。q = 1 のため）によって否定されるからである。
- 二層の構造になっている。**市場（労働余剰）が規範の適用の前提（要件）を決め、力（退出オプション）が規範の間の優先順位を決める**。

### (c) 慣習と法: 効力（当為、de jure）と実効性（存在、de facto）

- パート有期法 9 条（通常の労働者と同視すべき短時間・有期雇用労働者に対する差別的取扱いの禁止＝均等待遇）は、強行規定である。
- 民法 92 条の事実たる慣習は、任意規定と異なる慣習にしか効力を持たない。したがって**当為の層**では、9 条は身分秩序に常に優る。T4w でも T4s でも、周辺の結論は「低くてはならない」になる。
- **存在の層**では、執行の強さが慣行の持続を決める（Sim 3 の慣習の慣性）。
  - 弱い執行（罰 0.102 < 維持できなくする水準 0.241）では、「均等待遇の実効」の要件が否定される。慣行の例外として働かないので、「実際に低い」が残る。
  - 強い執行（0.265 > 0.241）では、「実際に低くない」に変わる。
- T4w は、「法の上では許されないが、事実としては切り下げが続く」という状態（Kelsen の効力と実効性の乖離）を、**二つの層の結論の食い違い**として形式的に示している。

**この区別は、AI の審査によって見つかった**（`skill_runs_v1/T4w_law_weak/`）。

- 最初の版は、9 条の効力そのものを執行の強さで外していた。スキルの審査は、これを「実効と効力の混同（最重要）」と指摘し、9 条は強行規定で民法 92 条の慣習に優ることを根拠に挙げた。あわせて「均衡待遇」という呼び名の誤り（9 条は均等待遇、均衡待遇は 8 条）も指摘した。
- 雇用形態の理論（`skill_runs_v1/T1_employment/`）については、「事実上の規範が法律上の原則を破って『すべきでない』と結論するのは、存在から当為を導いている」という指摘があった。
- 地域をまたいで事実の原子が共有されているという問題も指摘された。
- これらを受けて生成器を直し、現在の版にした。決定論的な検査（構文・Extension・Lean）では見つからない種類の誤りを、AI の実質審査が見つけ、それを人（と生成器）が直す。これは本レポートの neuro-symbolic な分業が働いた実例である。

### (d) アブダクション: 観測された慣行を説明する規範はどれか

観測（Sim 3）は「中核では非正規の賃金は低くない（B 0%）、周辺では低い（B 97%）」である。これを `[claimed]` に書き、候補となる規範の組を `verify` で検査した。

| 候補の規範の組 | 両立する（信憑的） | 導く（懐疑的） |
|---|---|---|
| 補償原則のみ（T5） | ✗ | ✗ |
| 身分秩序のみ（普遍的な規範として、T6） | ✗ | ✗ |
| 補償原則 ＋ 身分秩序（要件付き）（T2） | ✓ | ✗ |
| 補償原則 ＋ 身分秩序 ＋ 力による優先順位（T3） | ✓ | ✓ |

事実 → 評価（判例・慣習）→ 規範、というアブダクション（Grok 会話の論点）を、「候補の規範が観測された評価を Extension として再現するか」という形で検査できる。観測を導けるのは、事実を要件とする慣習（身分秩序）に、力から来る優先順位を加えた組だけである。

### (e) 周辺の不平等は中核に及ばない、の意味

- Sim 1 の需要の経路では、周辺の所得の総額へのショックは中核にも波及する（正直に記録した結果）。
- しかし賃金の規範については、中核と周辺は分離されている。中核の結論は、どの理論（T2〜T4s）でも同じである。周辺の慣行がどう変わっても、中核の Extension は変わらない。
- 周辺の身分賃金による差額は、外資を通じて中核に移転する（Sim 2）。

## 3. スキルによる AI の審査

- `skill_runs_v1/`: 最初の版に対する審査（T3、T4w、T1）。§2(c) の効力と実効性の混同などが見つかった。
- `skill_runs/`: 改訂版に対する審査（T4w、T1、T3）。求解していない `.mext` を渡したので、AI の予測は結果を見ないで行われた。

改訂版への主な指摘と、その扱いは次のとおり。

| 指摘 | 扱い |
|---|---|
| T1: 「正規が通常でなくなっている」の根拠が職全体の非正規の割合（0.51）で、対象の「安定した職」と量が合わない。安定した職の過半が非正規になるのは撤退ハザード 0.35 以上 | 対象を「外資の安定した職」に絞り、その中の非正規の割合（**0.497**。国内資本は 0）を根拠にした。ただし 0.497 は過半に届かない。「約半数で、国内資本と際立って異なるので、外資の職では正規は通常ではない」という `@評価` は争いうるあてはめとして残る（**留保**） |
| T4w: 9 条の二つの要件（職務の内容の同一、配置の変更の範囲の同一）を一つの評価にまとめている。事実「安定した職を非正規で埋めている」に出典がない | 二つの要件に分けた。前者は Sim 2 の値で裏づけ、後者は「モデルの設定（仮定）」と明記した |
| T3: 周辺の結論は、論理の外の二か所に支えられている。強いられた受け入れを民法 92 条の「慣習による意思」と読むこと（窮迫による受諾）と、法的な根拠のない力による優先順位である | 論証の**本質的な留保**として受け止め、IPYNB の考察で論じる。試算では、受け入れを強いられたものとすると、優先順位があっても補償原則が勝つ（`skill_runs/T3_power/T3_power.alt-coerced.mext`） |
| 道具: reject した評価を `explain` が「事実が書かれていない」と説明する | 直した（「review で棄却された」と表示する） |

これらの留保は、形式化によって人が追えるようになった論証の弱点である。決定論的な検査（構文、Extension、Lean）はすべて通っている。そのうえで残るのは、事実から評価への**あてはめ**（neuro の部分）と、**優先順位の出どころ**（論理の外）である。これはまさに、本レポートが「形式化によって可視化したかったもの」にあたる。
