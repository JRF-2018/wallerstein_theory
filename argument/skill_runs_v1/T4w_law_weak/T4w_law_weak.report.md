# Extension レポート: T4w_law_weak（wage_core.matcha + wage_periphery.matcha + power_periphery.matcha + law_periphery_weak.matcha）

4 つのファイルを一つの理論として扱った（`T4w_law_weak.mext` の `theory:` 行）。各ファイルは `argument/build_argument.py` が `sims/out/*.json`（Sim 2・Sim 3）から生成したもの。主題は「周辺で均衡待遇（パート有期法9条）を弱く執行した場合、身分秩序（民法92条の事実たる慣習）による非正規の賃金切り下げは崩れるか」である。

## 2. AI の判断（[ai] / [extra]）

### same / neg / failure / effect

なし。理由:

- 中核と周辺の要件（「補償原則_中核／%雇用が不安定」と「補償原則_周辺／%雇用が不安定」など）は、対象の契約が違う別の主張の要件なので、同一視しない。`[marks]` に「不一致」を起こす未解決の繰り返し要件もない。
- 共通の事実「非正規の層は契約の切れ目で0.2の割合で職がない」（Sim 2 のパラメタ e0）は、文言が同じなので変換の時点で一つの原子 f2・v1 になっている。これは意図どおり。
- 結論の型は既定の読みで正しい: `!#身分秩序`（中核）と `!#均衡待遇の実効` の結論は「不成立からの帰結」、`+#身分秩序`（周辺）の結論は「成立の効果」、補償原則は `>> !` で `-c` になっている。

| + | 「通常の労働者と同視すべき短時間・有期雇用労働者」 | law_periphery_weak:L5 | 一致 | 一致 |
| ! | %実効的な執行 | law_periphery_weak:L7 | 一致 | 一致 |
| ! | #均衡待遇の実効 | law_periphery_weak:L4 | 一致 | 一致 |

preferred の E2 ではすべて一致する。E1 の不一致（周辺の `+#身分秩序` が E1 に含まれない）は、E1 が優先順位を無視して補償原則_周辺を先に適用した Extension だからであり、原典の誤記でも変換の読みの問題でもない。著者の印は、力による優先順位まで含めた preferred Extension を描いている。

## 6. あてはめの実質的妥当性

review の表は §2 のとおり（ok 5、doubtful 2、reject 0）。reject がないので、書かれたとおりの理論（`X.asis.mext`）は本体と**同一**であり、作っていない。

### 6.1 9条の「実効」と「効力」の混同（構造の問題、最も重要）

この論証の要は、「パート有期法9条の執行が弱いので、例外 `!> $身分秩序_周辺` が働かず、身分秩序（民法92条）が残る」という筋である。形式的にはこのとおり導かれる（§4）。しかし法的には次の点が問題になる。

- 民法92条の事実たる慣習は、**任意規定と異なる**慣習についてだけ、当事者の意思を介して効力を持つ（民法91条・92条）。強行規定に反する慣習は効力を持たない。
- パート有期法9条（差別的取扱いの禁止）は強行規定と解されており、違反は不法行為（民法709条）として損害賠償の根拠になる。その私法上の効力は、行政による執行の強さに依存しない。
- 原典では、9条の主張に「%実効的な執行」という要件を AND で加え、その不成立によって主張全体（#均衡待遇の実効）を不成立にしている。これは社会学的な**実効性**（守られているか）の判断としては正しい。主張名も「実効」となっている。しかし同じ主張に `!> $身分秩序_周辺` を付けているので、「実効がない」ことが「92条による慣習が法的に排除されない」ことにまで及んでいる。

つまり、結論 c3「非正規の賃金は正規より低くてよい〔周辺〕」は、**事実として（de facto）そうなっている**という意味では支持されるが、**法的に許される**という意味では、9条の要件 r7 が E2 に入っている（§3、+ の印とも一致）以上、支持されない。試算 `alt-mandatory`（§8）で、9条の効力を実効から切り離すと結論が反転することを示した。

ウォーラーステインの議論に引きつけて言えば、この論証が示しているのは「周辺では法が存在しても慣習（力関係）が優る」という**法の実効性の欠如**である。「法がそれを許している」ではない。本文で使うときは、c3 を規範命題ではなく事実命題として読むよう注記すべきだと考える。

### 6.2 「均衡待遇」と 9条（誤記の疑い）

主張名とラベルは「均衡待遇」だが、根拠は「パート有期法9条」、要件は 9条の文言「通常の労働者と同視すべき短時間・有期雇用労働者」である。9条は一般に**均等待遇**（差別的取扱いの禁止）と呼ばれ、「均衡待遇」（不合理な待遇の禁止）は 8条である。9条を意図しているなら「均等待遇」、均衡待遇を意図しているなら根拠を 8条にし、要件を「職務の内容、配置の変更の範囲その他の事情を考慮して不合理と認められる相違」に改めるのがよい。どちらに直しても、本理論の Extension の構造（実効的な執行の否定によって主張が不成立になる）は変わらない。ただし 8条にすると、v6 の審査（§2、doubtful）の問題は小さくなる。8条は職務・配置の完全な同一を要件としないからである。`build_argument.py` 側の文言の問題なので、ファイルは直していない。

### 6.3 doubtful の 2 点

- **v5「受け入れる」**: シミュレーションの「身分賃金 0.629 が正規職の列に並ぶ価値 0.563 を上回る」は、周辺では外部の選択肢が乏しいことの帰結である。これを民法92条の「慣習による意思」と読むのは、窮迫下の受諾を自由な意思と同視することになり、争いうる。この評価を否定すると結論が反転する（試算 `alt-noaccept`、§8）。
- **v6「職務の内容と配置の変更の範囲が同一」**: 事実「安定した職を非正規で埋めている」は職務内容の同一を示唆するにとどまる。全期間の配置変更範囲の同一を示す事実がない。ただし本理論では、この要件 r7 が否定されても −x3 は −r8 からすでに出ているので、Extension は変わらない（r7 は結論に効いていない）。§6.1 の反論（9条の効力）を立てるときには、この評価が決定的になる。

### 6.4 事実の食い違い

ファイル間に事実の矛盾は見当たらない。周辺の数値（o_F ≈ 0.08、freq_B 0.978、wB 0.629 > uW 0.563、penalty_weak 0.102 < 0.241）は互いに整合しており、中核の数値（freq_B 0、wB 2.209 < uW 2.548）も同様である。

## 7. 懐疑的帰結と信憑的帰結

（mext.py の出力。preferred Extension について）preferred は E2 だけなので、両者は一致する。

- 懐疑的 = 信憑的: k1（補償原則・中核）、¬c1（中核の非正規の賃金は低くてはならない）、¬k2、c2（中核では身分秩序による切り下げは認められない）、**c3（周辺の非正規の賃金は低くてよい）**、k4（身分秩序・周辺）、¬k5、c4（周辺では均衡待遇は実効を欠く）。

すべての Extension（優先順位を無視）で見ると、c3 は E2 にしかなく、E1 では ¬c3 になる。周辺の結論が成り立つのは、力による優先順位（power_periphery.matcha）があるからだけである。中核の結論（¬c1, c2）と c4 は、優先順位に関係なく両方の Extension で成り立つ。

## 8. 反論の候補（立証責任）

周辺の結論 c3 を覆して ¬c3（補償原則）に移す道は、次の三つである。いずれも**試算**で、本体の理論は変えていない。三つとも Extension は 1 個（preferred）になり、周辺の結論は ¬c3 になった（mext.py の出力: `[summary]`）。

| 試算 | 変更 | Extension | 周辺の帰結（skeptical） |
|---|---|---|---|
| `T4w_law_weak.alt-mandatory.mext` | [extra] に `default 強行規定_9条: r7 : ab1 / ab1` と `priority 強行規定_9条 > 身分秩序_周辺` | 1（preferred） | k3, **¬c3**, ¬k5, c4 |
| `T4w_law_weak.alt-enforce.mext` | v7 を reject、[extra] に `fact "均衡待遇_周辺／%実効的な執行"` | 1（preferred） | k3, **¬c3**, **k5** |
| `T4w_law_weak.alt-noaccept.mext` | v5 を reject | 1（preferred） | k3, **¬c3**, ¬k5, c4 |

1. **9条の私法上の効力を主張する（alt-mandatory）**: 労働者側が、9条の対象であること（r7、すなわち職務内容と配置変更範囲の同一）を立証すれば、執行の実効がなくても慣習は排除される。この試算では「均衡待遇は実効を欠く」（c4）と「周辺の非正規の賃金は低くてはならない」（¬c3）が同時に成り立つ。§6.1 で述べた「実効はないが効力はある」状態である。立証の焦点は v6（doubtful）、つまり配置変更範囲の同一に移る。
2. **執行を強める（alt-enforce）**: 制裁による利潤の減少が水準 0.241 を上回れば、%実効的な執行 が成立し、k5 と ab1 によって身分秩序_周辺が阻却される。これは T4 の強い執行の場合（別のラン）に対応する。立証責任というより政策の変数である。
3. **受諾を争う（alt-noaccept）**: 周辺の労働者の受諾が窮迫によるもので「慣習による意思」に当たらないと主張する。v5 が否定されると r6 が立たず、身分秩序_周辺の前提 x2 が欠ける。ただし ¬r6 は導かれない（不成立の根拠を足していない）ので、立証されていないだけの状態である。それでも補償原則_周辺が働く。

なお中核の結論は、どの試算でも変わらない。

## 10. 結論

**(a) 形式的妥当性**: 成り立つ。著者の印（+ / !）は preferred Extension E2 とすべて一致する。主要な結論、「周辺では均衡待遇は実効を欠く」（c4）、「周辺の非正規の賃金は正規より低くてよい」（c3）、「中核では身分秩序による切り下げは認められない」（c2）は、いずれも E2 に含まれ、懐疑的帰結である。Lean による Γ(E)=E の確認も通った。ただし c3 は、力による優先順位（power_periphery.matcha）を前提にしてはじめて懐疑的帰結になる。優先順位を外すと、補償原則による E1（¬c3）も Extension として残る。

**(b) 実質的妥当性**: 「弱い執行では身分秩序が慣性で続く」という**事実の記述**としては説得的である。数値の比較 0.102 < 0.241 によるあてはめに飛躍はない。しかし c3 を「法的に許される」という**規範命題**として読むと、説得的ではない。9条は強行規定であり、92条の慣習は強行規定に優らない。それにもかかわらずこの論証は、9条の効力を執行の実効に結びつけて排除している（§6.1、試算 alt-mandatory で反転）。加えて、周辺の労働者の「受諾」を慣習による意思と読む評価 v5 は争いうる（試算 alt-noaccept で反転）。また「均衡待遇」と 9条（均等待遇）の呼び名が合っていない（§6.2）。IPYNB で使うときは、c3 を「周辺では法がありながら、事実として非正規の賃金切り下げが続く」と読み、「法の実効の欠如」と「法の効力」を区別して書くことを勧める。

## 道具について

- Bash の制約により、シェル変数や `$?` を含むコマンドが実行できなかった。パスを直接書いて回避した（mext.py 自体の問題ではない）。
- `[extra]` の `fact` に要件の原子の文言（「均衡待遇_周辺／%実効的な執行」）を指定でき、`default` の結論に `ab(…)` 原子を指定できた。どちらも期待どおり動いた。
